AQUA NOIR - interactive WebGL experience

How to run
  Open index.html in a modern browser (Chrome, Brave, Firefox, Safari).
  Needs an internet connection: Three.js r128 (cdnjs) and Google Fonts are loaded from the web.

Files
  index.html              markup only
  css/styles.css          all styles
  js/text-ui.js           menu, tagline phrases, hold text, captions, tips
  js/intro-loader.js      opening loader
  js/hero-text-fx.js      WebGL title effect + cosmic dust
  js/scenes.js            droplet, tunnel, shard and lighter scenes
  droplet-loader.html     the same project as one single file

How to use
  Wait for the loader, then press and hold the click anywhere.
  Each hold opens the next scene: tunnel -> shards -> lighter scene. Release to return to the droplet.
